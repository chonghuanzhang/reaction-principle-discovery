  <h2 class="bsmArticleDetailAbstract">Abstract</h2>

  
  <p>In this study, we develop the synthesis methods of fluoroalkenes and fluoroenynes via Suzuki&#8211;Miyaura and Sonogashira cross-coupling reactions using novel multihalogenated fluorovinyl ethers, which are easily prepared from the reaction between phenols and 2-bromo-2-chloro-1,1,1-trifluoroethane (halothane). These reactions make use of the unique structure of multihalogenated fluorovinyl ethers, which contains a reactive bromine atom, to afford a series of fluoroalkenes and fluoroenynes in moderate to high yields.</p>

    <a id="O2"></a>
    <h2 class="bsmSectionTitle">Introduction</h2>


    

      
        <p>Fluoroalkenes are one of the important frameworks for a wide range of industrial fields. For example, they are used as a bioisostere of amide bonds in medicines and agrochemicals, and contribute to the synthesis of peptide medicines that are stable to enzymatic metabolism and possess high lipophilicity <button  class='popoverButton' id='link1' tabindex='0' role='button' data-template='link1-content'>[1]</button>. In fact, several inhibitors of the &#946;-site amyloyd &#946; A4 precursor protein cleaving enzyme (BACE1), which is involved in the production of &#946;-amyloid, and fluoroalkene analogs of dipeptidyl peptidase-4 inhibitors have previously been reported <button  class='popoverButton' id='link2' tabindex='0' role='button' data-template='link2-content'>[2,3]</button>. These inhibitors possess higher drug efficacies than their parent compounds. Furthermore, fluoroalkenes can be utilized as feedstock for fluoropolymers. Teflon, which is a well-known fluoropolymer with excellent water-repellent and oleophobic properties, is synthesized by polymerizing a monomer called tetrafluoroethylene. As a consequence, convenient and diverse synthetic methods for fluoroalkenes have attracted considerably and become increasingly necessary in pharmaceutical and industrial fields.</p>
        
        
        
        
        
      

    

      
        <p>Fluoroalkenes have been constructed in a variety of methods <button  class='popoverButton' id='link3' tabindex='0' role='button' data-template='link3-content'>[4-14]</button>, and one of the methods is to make use of fluorine-containing building blocks. When using them as nucleophilic reagents <button  class='popoverButton' id='link4' tabindex='0' role='button' data-template='link4-content'>[15-20]</button>, the reaction between anion species, such as fluorine-containing Horner&#8211;Wadsworth&#8211;Emmons reagents, and carbonyl compounds led to <i>E</i>-selective olefination (<a href='#S1'>Scheme&#160;1A</a>) <button  class='popoverButton' id='link5' tabindex='0' role='button' data-template='link5-content'>[15]</button>. On the other hand, some reactions with electrophilic fluorine-containing building blocks have been developed <button  class='popoverButton' id='link6' tabindex='0' role='button' data-template='link6-content'>[21-25]</button>. Jubault and Poisson et al. reported S<sub>N</sub>2&#8217; reactions of hydride or alcohols to electrophilic fluorine-containing alkenes gave the corresponding fluoroalkenes (<a href='#S1'>Scheme&#160;1B</a>) <button  class='popoverButton' id='link7' tabindex='0' role='button' data-template='link7-content'>[21]</button>. In recent years, many fluorine-containing coupling reagents have been developed. These reagents are easily being converted into multisubstituted fluoroalkenes through cross-coupling using palladium, nickel, copper, ruthenium, and manganese catalysts <button  class='popoverButton' id='link8' tabindex='0' role='button' data-template='link8-content'>[26-41]</button>. Hosoya and Niwa et al. published the development of a dual-reactive fluorine-containing C2-unit, which was prepared from trifluoroethanol in two steps in 63% yield, allowed the convergent synthesis of fluoroalkenes (<a href='#S1'>Scheme&#160;1C</a>) <button  class='popoverButton' id='link9' tabindex='0' role='button' data-template='link9-content'>[26]</button>. We recently found multihalogenated vinyl ethers <b>1</b> could be obtained by the reaction of phenols with 2-bromo-2-chloro-1,1,1-trifluoroethane (halothane) in good yields (<a href='#S1'>Scheme&#160;1D</a>) <button  class='popoverButton' id='link10' tabindex='0' role='button' data-template='link10-content'>[42]</button>. Compound <b>1</b> has a unique structure possessing three types of halogen atoms, namely bromine, chlorine, and fluorine, and it would be expected to afford multisubstituted fluoroalkenes by installing various substituents to bromine or chlorine atoms as reported by Hosoya and Niwa et al. In this study, we investigated the synthesis of fluoroalkenes <b>2</b> or fluoroenynes <b>3</b> by Suzuki&#8211;Miyaura or Sonogashira cross-couplings with a key building block <b>1</b> (<a href='#S1'>Scheme&#160;1D</a>).</p>

    <a id="O3"></a>
    <h2 class="bsmSectionTitle">Results and Discussion</h2>


    

    

      <a id="O4"></a>
      <h3>Optimization of the conditions of cross-coupling reactions</h3>
      
        
          <p>First, we optimized the conditions of the Suzuki&#8211;Miyaura cross-coupling in reference to the report by Yang et al. (<a href='#T1'>Table&#160;1</a>) <button  class='popoverButton' id='link11' tabindex='0' role='button' data-template='link11-content'>[43]</button>. Upon the treatment of multihalogenated vinyl ether <b>1a</b> with phenylboronic acid <b>4a</b> (1.3 equiv) and palladium diacetate (10 mol %) as a catalyst at 40 &#176;C, Suzuki&#8211;Miyaura cross-coupling proceeded to produce fluoroalkene <b>2a</b> in 50% yield (<a href='#T1'>Table&#160;1</a>, entry 1). Increasing the amount of <b>4a</b> to 2.0 equiv and decreasing the amount of palladium diacetate to 5 mol % improved the reaction yield (<a href='#T1'>Table&#160;1</a>, entry 2). When the reaction mixture was heated to 60 &#176;C or reflux conditions, <b>2a</b> could be synthesized in 84% yield under reflux conditions (<a href='#T1'>Table&#160;1</a>, entries 3 and 4). Next, we examined an effective catalyst for the cross-coupling. Reactions using palladium dichloride or bis(2,4-pentanedionato)palladium significantly reduced the yields of <b>2a</b> (<a href='#T1'>Table&#160;1</a>, entries 5 and 6, respectively). When an allylpalladium chloride dimer or bis(triphenylphosphine)palladium dichloride were used as catalyst, the reaction proceeded with the same yield as that in <a href='#T1'>Table&#160;1</a>, entry 4 (entries 7 and 8). Utilizing palladium catalyst such as bis(triphenylphosphine)palladium dichloride, all these reactions could convert <b>1a</b> into <b>2a</b> in good yields (<a href='#T1'>Table&#160;1</a>, entries 9&#8211;11). Cross-coupling with palladium bis(trifluoroacetate), which is more reactive than palladium diacetate, gave the corresponding product in high yield of 96% (<a href='#T1'>Table&#160;1</a>, entry 12). Without the addition of triphenylphosphine, the reaction proceeded in only 12% yield (<a href='#T1'>Table&#160;1</a>, entry 13). Thus, it was concluded that triphenylphosphine is necessary for Suzuki&#8211;Miyaura cross-coupling of <b>1</b> with <b>4</b> and that it is involved in the production of palladium(0).</p>

          <p>Next, the reaction conditions for the Sonogashira cross-coupling were optimized (<a href='#T2'>Table&#160;2</a>). On the basis of a previous study by Thorand <button  class='popoverButton' id='link12' tabindex='0' role='button' data-template='link12-content'>[44]</button>, we performed the reaction between fluorine-containing vinyl ether <b>1a</b> and 1.05 equiv of trimethylsilylacetylene (<b>5a</b>) to afford the corresponding enyne <b>3a</b> in 55% yield (<a href='#T2'>Table&#160;2</a>, entry 1). Cross-coupling utilizing a palladium(II) catalysts containing phosphine ligands produced low yields of <b>3a</b> (<a href='#T2'>Table&#160;2</a>, entries 2 and 3). In the case of palladium(II), which produced good yields of the Suzuki&#8211;Miyaura cross-coupling products, only a small amount of <b>3a</b> was obtained (<a href='#T2'>Table&#160;2</a>, entries 4&#8211;8). In particular, when the allylpalladium dichloride dimer was used, Sonogashira coupling hardly proceeded at all, and the starting ether <b>1a</b> was recovered in an 83% yield (<a href='#T2'>Table&#160;2</a>, entry 6). Zero-valent tetrakis(triphenylphosphine)palladium and tris(dibenzylideneacetone)dipalladium allowed the reaction to undergo in 37% or 23% yields, respectively (<a href='#T2'>Table&#160;2</a>, entries 9 and 10). In entry 11, <a href='#T2'>Table&#160;2</a>, we selected bis(triphenylphosphine)palladium as an effective catalyst, but increase of <b>5a</b> to 1.5 equiv did not improve the reaction yield. Diluting the reaction concentration from 0.83 M to 0.2 M achieved to give <b>3a</b> in a 63% yield (<a href='#T2'>Table&#160;2</a>, entry 12). Increasing the amount of palladium catalyst to 4 mol % led to the conversion of <b>1a</b> into <b>3a</b> in 77% yield (<a href='#T2'>Table&#160;2</a>, entry 13). In addition, using 2.0 equiv of <b>5a</b> gave <b>3a</b> in high 80% yield (<a href='#T2'>Table&#160;2</a>, entry 14).</p>

      <a id="O5"></a>
      <h3>Substrate scope for cross-coupling reactions</h3>
      
        
          <p>The substrate scope was investigated using various boronic acids <b>4</b> and alkynes <b>5</b> in cross-coupling reactions using <b>1</b> (<a href='#T3'>Table&#160;3</a> and <a href='#T4'>Table&#160;4</a>). <i>p</i>-Tolylboronic acid <b>4b</b> provided <b>2b</b> quantitatively, whereas <i>m</i>- and <i>o</i>-tolylboronic acids <b>4c</b> and <b>4d</b> produced <b>2c</b> and <b>2d</b> in low yields because the methyl group was positioned near the reaction site (<a href='#T3'>Table&#160;3</a>, entries 1&#8211;3). Introduction of 3,4-methylenedioxyphenyl (<b>4e</b>) or <i>p</i>-fluorophenyl groups (<b>4f</b>) to <b>1a</b> proceeded in high yields (<a href='#T3'>Table&#160;3</a>, entries 4 and 5). Boronic acids with carbonyl groups such as acetyl, ester or formyl moieties in <i>para</i> position (<b>4g</b>&#8211;<b>i</b>) underwent the cross-coupling in 76, 96 or 77% yields (<a href='#T3'>Table&#160;3</a>, entries 6&#8211;8). The reaction between <b>1a</b> and <b>4j</b>, which contains an electron-withdrawing nitro group, afforded <b>2j</b> in 88% yield (<a href='#T3'>Table&#160;3</a>, entry 9). Although <i>p</i>-hydroxyphenylboronic acid (<b>4k</b>) gave <b>2k</b> in only 9% yield, <i>m</i>-aminophenylboronic acid (<b>4l</b>) provided <b>2l</b> in high yield (<a href='#T3'>Table&#160;3</a>, entries 10 and 11). We predicted that the product yield would decrease because <b>2k</b> is labile in column chromatography. Utilizing a boronic acid bearing an <i>n</i>-butyl group as a primary alkyl group (<b>4m</b>), the cross-coupling did not proceed due to &#946;-elimination (<a href='#T3'>Table&#160;3</a>, entry 12). In contrast, the reaction with cyclopropylboronic acid (<b>4n</b>) achieved to give <b>2n</b> in a 71% yield (<a href='#T3'>Table&#160;3</a>, entry 13). When thiopheneboronic acid <b>4o</b> was used as a coupling partner, the thiophene ring could be installed on <b>1a</b> in a comparatively low yield of 31% (<a href='#T3'>Table&#160;3</a>, entry 14). In addition, we investigated the substrate scope of <b>1</b> in the Suzuki&#8211;Miyaura cross-coupling. The reaction of <b>1b</b> or <b>1c</b>, which had a <i>m</i>-methoxy or <i>p</i>-nitro group on the benzene ring, with <b>4a</b> proceeded smoothly to furnish <b>2p</b> or <b>2q</b> in good yieds (<a href='#T3'>Table&#160;3</a>, entries 15 and 16). A phenyl group could be introduced into <b>1d</b> possessing an ester moiety in moderate yield, whereas the cross-coupling between <b>1e</b>, derived from <i>m</i>-aminophenol, and <b>4a</b> proceeded in only 15% yield (<a href='#T3'>Table&#160;3</a>, entries 17 and 18).</p>

          <p>We performed Sonogashira cross-couplings between <b>1</b> and a variety of alkynes <b>5</b> (<a href='#T4'>Table&#160;4</a>). Arylacetylenes, which have electron-donating substituents on the aromatic ring (<b>5b</b>&#8211;<b>f</b>), and 2-naphthylacetylene (<b>5g</b>) provided the corresponding enynes (<b>3b</b>&#8211;<b>g</b>) in 43&#8211;92% yields (<a href='#T4'>Table&#160;4</a>, entries 1&#8211;6). On the contrary, electron-withdrawing substituents such as chloro, trifluoromethyl and nitro groups resulted in low cross-coupling yields (<b>3h</b>&#8211;<b>j</b>) (<a href='#T4'>Table&#160;4</a>, entries 7&#8211;9). <i>p</i>-Acetyl or <i>p</i>-formylphenylacetylene (<b>5k</b> or <b>5l</b>) could be introduced into <b>1a</b> in 76% or 52% yields, respectively (<a href='#T4'>Table&#160;4</a>, entries 10 and 11). Reactions using acetylenes possessing a hydroxy group, amino group and thiophene proceeded well (<b>3m</b>&#8211;<b>o</b>) (<a href='#T4'>Table&#160;4</a>, entries 12&#8211;14). Hexa-1-yne <b>5p</b> and cyclopropylacetylene (<b>5q</b>) afforded <b>3p</b> and <b>3q</b>, respectively, in high yields without byproduct formation (<a href='#T4'>Table&#160;4</a>, entries 15 and 16). Enyne compound <b>5r</b> and 3-butyn-1-ol <b>5s</b> also participated in cross-coupling reactions and products <b>3r</b> and <b>3s</b> could be obtained in moderate yields of 52 and 53% (<a href='#T4'>Table&#160;4</a>, entries 17 and 18). Then, we attempted the cross-coupling between <b>1</b> derived from various phenols and <b>5a</b>. Vinyl ethers <b>1b</b>&#8211;<b>d</b> were converted into enynes <b>3t</b>&#8211;<b>v</b> in 29&#8211;35% yields (<a href='#T4'>Table&#160;4</a>, entries 19&#8211;21). The reaction using <b>1e</b>, which bears an amino group on the benzene ring, did not complete despite requiring a long reaction time (<a href='#T4'>Table&#160;4</a>, entry 22).</p>

    <a id="O6"></a>
    <h2 class="bsmSectionTitle">Conclusion</h2>


    

      
        <p>We used Suzuki&#8211;Miyaura and Sonogashira cross-coupling to exploit the unique structure of multihalogenated fluorovinyl ethers <b>1</b> for the synthesis of many kinds of fluoroalkenes <b>2</b> and fluoroenynes <b>3</b> in moderate to high yields. The synthesized alkenes <b>2</b> still possess reactive chlorine atoms and phenoxy groups. Thus, new multisubstituted fluoroalkenes could be synthesized by applying other cross-couplings to <b>2</b>. In addition, enynes <b>3</b> could be converted into derivatives, such as fluorine-containing alkynylalcohols <button  class='popoverButton' id='link14' tabindex='0' role='button' data-template='link14-content'>[47]</button>, allene compounds <button  class='popoverButton' id='link15' tabindex='0' role='button' data-template='link15-content'>[48-50]</button>, and heterocycles <button  class='popoverButton' id='link16' tabindex='0' role='button' data-template='link16-content'>[51,52]</button>. However, further experiments are required to expand the abilities of <b>2</b> and <b>3</b> as new fluorine-containing building blocks.</p>

      <a id="O8"></a>
      <h3>General information</h3>

      <a id="O9"></a>
      <h3>Materials</h3>
      
        
          <p>All commercially available materials were used as received without further purification. All experiments were carried out under argon atmosphere in flame-dried glassware using standard inert techniques for introducing reagents and solvents unless otherwise noted.</p>
          
          
          
          
          
        
      
      

    

      <a id="O10"></a>
      <h3>Suzuki&#8211;Miyaura cross-coupling with multihalogenated vinyl ethers <b>1</b></h3>
      
        
          <p>To a solution of <b>1</b> (1.0 equiv), triphenylphosphine (10 mol %), cesium carbonate (1.5 equiv), palladium bis(trifluoroacetate) (5 mol %) in THF (2.0 mL) was added the respective boronic acid derivative <b>4</b> (2.0 equiv). The reaction solution was refluxed for 3.5 h. The reaction mixture was quenched by the addition of water (40 mL) at 0 &#176;C and extracted with EtOAc. The organic phase was washed with brine (40 mL), dried over Na<sub>2</sub>SO<sub>4</sub> and filtered. Then, the filtrate was concentrated under reduced pressure. The residue was purified by column chromatography and preparative TLC to afford <b>2</b>.</p>
          
          
          
          
          
        
      
        
          <p><b>2-Chloro-1-fluoro-2-phenylethenyl phenyl ether (2a):</b> Compound <b>2a</b> was purified by column chromatography and preparative TLC (hexane only), and obtained in 96% yield (122.0 mg) as a pale yellow oil; <sup>1</sup>H NMR (400 MHz, CDCl<sub>3</sub>) &#948; 7.04&#8211;7.22 (m, 2H), 7.26&#8211;7.50 (m, 6H), 7.55&#8211;7.69 (m, 2H); <sup>13</sup>C NMR (100 MHz, CDCl<sub>3</sub>) &#948; 101.4 (d, <i>J</i> = 30.9 Hz), 102.5 (d, <i>J</i> = 48.0 Hz), 116.5 (d, <i>J</i> = 3.8 Hz), 124.8, 127.3, 127.4, 127.9 (d, <i>J</i> = 3.2 Hz), 128.2 (d, <i>J</i> = 5.5 Hz), 128.5 (d, <i>J</i> = 7.2 Hz), 128.6 (d, <i>J</i> = 11.8 Hz), 128.9, 130.1 (d, <i>J</i> = 4.2 Hz), 132.46 (d, <i>J</i> = 5.7 Hz), 132.52, 141.3, 151.2 (d, <i>J</i> = 286.1 Hz), 151.5 (d, <i>J</i> = 287.3 Hz), 154.3 (d, <i>J</i> = 3.4 Hz), 154.4 (d, <i>J</i> = 3.3 Hz); <sup>19</sup>F NMR (376 MHz, CDCl<sub>3</sub>) &#948; &#8722;80.8 (s) and &#8722;87.6 (s) (1F, 1:1.1); EIMS (<i>m</i>/<i>z</i>): 248, 250 [M]<sup>+</sup>; HREIMS [M]<sup>+</sup> (<i>m</i>/<i>z</i>): calcd. for C<sub>14</sub>H<sub>10</sub>ClFO, 248.0402; found, 248.0404.</p>
          
          
          
          
          
        
      
      

    

      <a id="O11"></a>
      <h3>Sonogashira cross-coupling with multihalogenated vinyl ethers <b>1</b></h3>
      
        
          <p>To a solution of <b>1</b> (1.0 equiv), copper iodide (4 mol %), bis(triphenylphosphine)palladium dichloride (4 mol %) and triethylamine (1.5 equiv) in THF (2.5 mL) was added the respective alkyne <b>5</b> (2.0 equiv). The reaction solution was stirred at room temperature until <b>1</b> was disappeared. The reaction mixture was evaporated and concentrated under reduced pressure. The residue was purified by column chromatography and preparative TLC to afford <b>3</b>.</p>

    let currentPid = "1860-5397-20-226";
    let journal = "bjoc";
    let pidList = getPublicIdList();

    let pager = document.getElementById("pager");
    let nextButton = document.getElementById("nextBtn");
    let previousButton = document.getElementById("previousBtn");
    let backButton = document.getElementById("backBtn");

    backButton.addEventListener("click", backToArticleList);

    function initializePaging() {
      if (checkSessionStorage() === undefined) {
        pager.classList.add("hidden");
        backButton.classList.add("hidden");
      }

      if (pidList == null || pidList.length == 1 || !isCurrentPublicIdContainedIdList(currentPid)) {
        pager.classList.add("hidden");
        backButton.classList.add("hidden");
      }

      var nextPid = nextPublicId(currentPid);
      var prevPid = previousPublicId(currentPid);

      if (nextPid == -1) {
        nextButton.classList.remove("text-white");
        nextButton.classList.add("text-gray-400");
        nextButton.classList.add("cursor-not-allowed");
        nextButton.setAttribute("disabled", "disabled");
      }
      if (prevPid == -1) {
        previousButton.classList.remove("text-white");
        previousButton.classList.add("text-gray-400");
        previousButton.classList.add("cursor-not-allowed");
        previousButton.setAttribute("disabled", "disabled");
      }
    }


    function backToArticleList() {
      if (checkSessionStorage() === undefined) {
        return;
      }
      let backPage = getBackPage();
      document.location.href = `/${journal}/${backPage}`;
    }

    function gotoArticle(direction) {
      if (checkSessionStorage() === undefined) {
        return;
      }

      let targetPublicId;

      if (direction == "next") {
        targetPublicId = nextPublicId(currentPid);
      }
      if (direction == "previous") {
        targetPublicId = previousPublicId(currentPid);
      }

      let splitted = targetPublicId.split("-");
      let vol = splitted[2];
      let an = splitted[3];

      document.location.href = `/${journal}/articles/${vol}/${an}`;
    }

    document.addEventListener("DOMContentLoaded", initializePaging);

    const globalTriggerBtn = document.getElementById("global-album-trigger");

    if (globalTriggerBtn !== null) {
        globalTriggerBtn.addEventListener("click", function () {
            gallery.openGallery();
        });
    }

    const albumTriggerList = document.querySelectorAll(".js-album-trigger");
    albumTriggerList.forEach((elem, index) => openGallery(elem, index));

    function openGallery(button, index) {
        button.addEventListener("click", function () {
            // GA handling in album
            if ("bjoc" === getJournalName()) {
                gallery.openGallery(index + 1);
            } else {
                gallery.openGallery(index);
            }
        });
    }

    /**
     * Used to open a table in a gallery which
     * @param tableId the id of the table
     */
    function openTable(tableId) {
        const tableGallery = lightGallery(document.getElementById(tableId), {
            selector: "this",
            iframeMaxWidth: "95%",
            zoom: false,
            download: false,
            closable: true,
            counter: false,
            controls: true
        });
        tableGallery.openGallery();
    }
