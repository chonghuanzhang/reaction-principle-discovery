# Figure artwork

The main-figure overview and molecular artwork are in [main/](main/). The editable chemical schemes are supplied in [author_chemical_schemes.pptx](source/author_chemical_schemes.pptx).

Computational source data and figure-generation commands are documented in [code/](../code/) for the evidence and molecular analyses, and [optimization/](../optimization/) for Figure 5 and SI Figures 21–23. These data should be used when quantitative values are needed; graphical coordinates and surface interpolation do not represent additional measurements.
