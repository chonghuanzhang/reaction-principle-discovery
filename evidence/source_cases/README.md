# Source-specific donor and endpoint cases

These 17 cases keep donor form, substrate, activation, conditions and endpoint together. They include eight phosphorus cases, six selenium cases and three nitrogen-related controls. A positive first-stage product, failed later conversion and different reaction endpoint are separate observations. The 37% phosphorus first-stage result is therefore retained as positive evidence.
