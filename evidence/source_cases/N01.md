# N01 — N-methylaniline

N-Methylaniline gives the fluoroenamine in 82% reported yield in the source addition/elimination reaction. It provides a positive comparison with piperidine in N02, without establishing a general ranking of aromatic and aliphatic amines.

## Reaction context

| Chemical feature | Source-specific information |
|---|---|
| Donor or intermediate | N-methylaniline |
| Source substrate | N-methylaniline; Coradi substrate1 |
| Activation | NaHMDS-mediated addition/elimination |
| Assessed endpoint | fluoroenamine, one F |
| Reported outcome | 82%, SI S15. The stated source endpoint was reported. |

## Interpretation and transfer limits

No global rule that anilines outperform all aliphatic amines; source comparison only.
