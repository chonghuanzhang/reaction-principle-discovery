# L352 — Synthesis of fluoroalkenes and fluoroenynes via cross-coupling reactions using novel multihalogenated vinyl ethers

**Online reference 61; Tier 1.**

Yukiko Karuo; Keita Hirata; Atsushi Tarui; Kazuyuki Sato; Kentaro Kawai; Masaaki Omote. Synthesis of fluoroalkenes and fluoroenynes via cross-coupling reactions using novel multihalogenated vinyl ethers. Beilstein Journal of Organic Chemistry 20, 2691-2703 (2024). https://doi.org/10.3762/bjoc.20.226

[doi:10.3762/bjoc.20.226](https://doi.org/10.3762/bjoc.20.226)

## Chemical contribution

Reaction of halothane with phenols produced multihalogenated fluorovinyl ethers. For product 2a, fluorine and OPh occupy the same alkene carbon, with NMR and HRMS supporting the assigned structure. This source contributes a verified local C(F)–OAr connectivity and an alternative precursor route for oxygen-linked fluoroalkenes; matching that local motif does not establish the same starting-substrate class or the complete product framework of this project.
