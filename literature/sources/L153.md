# L153 — Palladium-Mediated Carbonylative Suzuki Coupling for DNA-Encoded Library Synthesis

**Online reference 77; Tier 1.**

Pratik R. Chheda; Nicholas Simmons; David P. Schuman; Zhicai Shi. Palladium-Mediated Carbonylative Suzuki Coupling for DNA-Encoded Library Synthesis. Organic Letters 24(28), 5214-5219 (2022). https://doi.org/10.1021/acs.orglett.2c02113

[doi:10.1021/acs.orglett.2c02113](https://doi.org/10.1021/acs.orglett.2c02113)

## Chemical contribution

Pinacol boronate esters performed similarly to boronic acids but produced somewhat more hydroxycarbonylation; several functional groups were tolerated, while an azolic Boc group was cleaved. The boronate scope included electronically varied, sterically hindered, fused-bicyclic, and heteroaryl boronic acids, generally with good conversion and only trace direct Suzuki product. The authors suggest that an on-DNA acyl-palladium complex could furnish di(hetero)aryl ketones if competing hydroxycarbonylation were sufficiently suppressed.
