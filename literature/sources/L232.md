# L232 — Nucleophilicity Prediction Using Graph Neural Networks

**Online reference 310; Tier 3.**

Wan Nie; Deguang Liu; Shuaicheng Li; Haizhu Yu; Yao Fu. Nucleophilicity Prediction Using Graph Neural Networks. Journal of Chemical Information and Modeling 62(18), 4319-4328 (2022). https://doi.org/10.1021/acs.jcim.2c00696

[doi:10.1021/acs.jcim.2c00696](https://doi.org/10.1021/acs.jcim.2c00696)

## Chemical contribution

Experimental determination of Mayr's nucleophilicity parameter N requires time-consuming reactions with reference electrophiles in the relevant solvent. The study used a solvent-dependent benchmark data set containing 894 data points across 15 nucleophile types and four solvents: dichloromethane, acetonitrile, dimethyl sulfoxide, and water. The authors conclude that Z-SchNet-CDFT has transfer-learning capability but recommend ensuring that the training set contains a broader range of nucleophilic-element types than the test set.

### L232-S005

**LITERATURE FACT**; candidate-generation evidence.

In leave-one-nucleophile-type-out evaluation, the C-I, C-M, C-Si, and C-B categories had RMSE values of 2.10 or lower; the authors associated this with transfer among categories whose nucleophilic atoms were mostly C(sp2).
