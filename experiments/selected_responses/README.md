# Selected N–H and O–H response records

`selected_responses.csv` and `.json` contain the same 120 scientific rows used for numerical reproduction: 60 each for NH_PL36 (seed 6000) and the O–H formulation–solvent library OH_CuNi_96 (seed 8000), in five computational batches of twelve. The table retains catalyst, catalyst–base formulation, base and solvent identities, together with physical source identifiers. The `archived_response` column is the recorded experimental analytical signal used in the model. Figure row axes use Formulation, meaning catalyst, ligand where present, and base/additive, with system-specific F1–F12 keys. N–H holds Ag2SO4/PPh3 fixed while varying the base/additive; O–H varies its specified catalyst–base formulation. The models use formulation and solvent identities and their interactions; the common display terminology does not change the deposited response records or numerical features.

The O–H library contains 12 catalyst–base formulations crossed with eight solvents (96 distinct measured conditions). Cu66/K3PO4 and Ni203/DIPEA are mandatory reference formulations because they contain the known highest-response Cu and Ni recipes; the other ten identities are sampled without replacement from the remaining 22 Cu/Ni–base formulations using Python random.Random(20261111). Thus library construction uses known reference information, whereas subsequent acquisition sees only selected responses. Cu66 denotes [Cu(MeCN)4]PF6 and Ni203 denotes NiCl2·DME. The formulation manifest records the complete construction rule and the source cell for every condition. The highest selected O–H response is 1.44247787610619 for DIPEA/DCE (PL38-W10), already included in the uniform random initial batch of the fixed library; later batches update the posterior and stopping diagnostics rather than first discover that response. The acquisition seed is 8000, with no seed search. The 12-formulation library construction and its separate seed are recorded in `../../optimization/selections/OH_CuNi_96/candidate_manifest.json`.

Each deposited grid contains 96 measured conditions; the numerical exports use only 60 labels per system for posterior updates, leaving 36 labels hidden from the policy and stopping rule. Exported seeds and batches define the numerical analysis and are not primary laboratory execution logs. Both calculations reach the 60-condition budget without meeting the two-consecutive-check stopping rule. The retrospective BO/random comparison concerns S–H.

N–H and O–H values are UV response. Responses are not calibrated yields. Source-linked selected rows and stopping checks are in `../../optimization/selections/`; the selected exports retain the exact raw workbook label `CsOH/2`. Immutable raw workbooks and historical benchmark tables retain their original contents.
