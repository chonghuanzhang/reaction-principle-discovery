# Archived S–H random-selection comparison

These 100 paired first-hit records belong to the preceding measured 96-condition analysis. They remain available as historical data and are not the current manuscript's baseline or Table R3. The current three-system trajectory and stopping table is [Table R3](../bo_trajectories/).

The original calculation used identical twelve-condition initializations and batches of twelve. `paired_first_hit_budgets.csv` and `.json` retain the unmodified records for seeds 5000–5099. Their median Bayesian/random first-hit counts are 24/48. The source records and historical reproduction code remain under `optimization/benchmark/`.
