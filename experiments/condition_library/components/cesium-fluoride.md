# CsF — cesium fluoride

Type: base/additive. Chemical role: fluoride activity/latent-donor activation.

Evidence level: exact component in related literature or seed. Exact component in fast coupling literature; fluoride activator/additive, not uniformly a Brønsted base.

Source support: [L071](../../../literature/sources/L071.md) [81]; [10.1002/chem.202101731](https://doi.org/10.1002/chem.202101731); PDF p2.
