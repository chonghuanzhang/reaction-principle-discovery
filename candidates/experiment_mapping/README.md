# Recommendation-to-experiment correspondence

This ledger contains the **112 ordered electrophile-donor pairs** used in the experimental collection: 45 N-H, 44 O-H, 21 S-H and two P-H records, representing 102 distinct donor structures. Each pair is linked to the RP-derived recommendation set using the intended bond-forming element, structure and donor form.

The pair-level best relationships are **27 exact identities, 39 same-scaffold/substituent or positional variations, 42 same-family/different-scaffold relations and 4 unmatched records**. These 112 pair-level counts differ from the 100-row recommendation-level summary because one reagent can occur with more than one electrophile and one recommendation can relate to more than one tested input.

- [Mapping JSON](mapping_112.json) · [CSV](mapping_112.csv) · [Table R1](table_R1.csv)
- [Selected recommendation-pair relations](relations.csv)
- [Qualitative supplemental phosphorus records](supplemental_phosphorus_records.json)

The supplemental phosphorus records identify reagents tested with no product detected but lack the complete ordered-pair fields required for inclusion among the 112 records.

The ledger links source structures to the screening workbooks and the [product structure register](../../experiments/raw/product_structure_register.xlsx), documented in its [manifest](../../experiments/raw/product_structure_register_manifest.json). Product identifiers, worksheet rows and source-file hashes are retained separately from sample and condition identifiers.
