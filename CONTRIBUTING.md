# Questions and corrections

For a chemical question, identify the literature source (L number), passage (Q number), candidate (C number), product option or experimental sample. Include the relevant publication or measurement and explain which interpretation or field needs correction. Distinguish an unmeasured outcome from an experimentally negative result.

For a code problem, include your operating system, Python version, installation command, the command you ran and its error message. Report the repository commit so that others can reproduce the same calculation. Please keep access tokens and licensed article files out of issue reports.

Changes to chemical structures, response values or source attribution should retain enough information to understand the previous value and the evidence for the correction. Code changes should be checked against the affected scientific outputs.
